# إزاي تضيف كورسات ومستويات

الملف ده ليك إنت — مش محتاج تعرف برمجة عشان تضيف محتوى للأكاديمية.

كل المحتوى ملفات نصية عادية في المجلد ده. **مفيش قاعدة بيانات، ومفيش لوحة تحكم**،
وكل حاجة بتتعمل بإضافة ملف.

---

## القاعدة الأساسية

> **تضيف مستوى جديد = تضيف ملف واحد.**
> مش محتاج تعدّل أي ملف تاني، ومفيش قايمة لازم تحدّثها. الموقع بيلاقي الملف لوحده.

---

## المجلدات

```
content/courses/
  ai-automation-engineer/          ← الكورس
    course.json                    ← بيانات الكورس
    levels/                        ← المستويات
      01-ai-problem-solver.md
      02-python-fundamentals.md
      ...
```

---

## تضيف مستوى جديد إزاي

**١.** اعمل ملف جديد جوه `levels/` بالاسم ده:

```
النمرة-اسم-المستوى-بالإنجليزي.md
```

مثال: `05-backend-development-databases.md`

> النمرة في أول الاسم للترتيب في المجلد بس. الترتيب اللي بيظهر في الموقع بييجي من
> `order` جوه الملف.

**٢.** افتح الملف واكتب في أوله البلوك ده بالظبط (بالشرطات):

```yaml
---
title: "Backend Development"
titleAr: "Backend Development"
subtitle: "اتعلم إزاي تبني الـ Backend وقواعد البيانات"
order: 5
status: "published"
---
```

**٣.** تحت البلوك ده اكتب المحتوى عادي.

**٤.** خلاص. المستوى هيظهر في الموقع.

---

## الحقول ومعناها

| الحقل | معناه | لازم؟ |
|-------|-------|-------|
| `title` | اسم المستوى بالإنجليزي | ✅ |
| `titleAr` | الاسم اللي هيظهر في الموقع | ✅ |
| `subtitle` | سطر وصف قصير تحت العنوان | ✅ |
| `order` | ترتيب المستوى (1، 2، 3...) | ✅ |
| `status` | حالة المستوى — اقرا تحت | ✅ |
| `vimeo` | رابط الفيديو | ❌ |
| `duration` | مدة الفيديو، مثلاً `"42:10"` | ❌ |

### `status` — تلات قيم بس

| القيمة | معناها |
|--------|--------|
| `"published"` | المستوى شغّال والناس تقدر تذاكره |
| `"coming-soon"` | لسه بيتكتب — بيظهر في القايمة مقفول، والناس تقدر تشوف هيتعلموا فيه إيه |
| `"draft"` | مسوّدة — بيظهر مقفول برضه. استخدمه وإنت لسه بتكتب |

> **مهم:** لو غلطت في كتابة `status` (مثلاً كتبت `publish` بدل `published`)،
> الموقع هيعتبره `draft` ومش هيظهر للناس. ده مقصود عشان محتوى نص مكتوب ما ينشرش
> بالغلط.

## تضيف فيديو إزاي

**١.** ارفع الفيديو على Vimeo.
**٢.** انسخ الرابط من Vimeo.
**٣.** حطّه في `vimeo` جوه الملف:

```yaml
vimeo: "https://vimeo.com/123456789"
```

**كل الأشكال دي شغالة** — الصق اللي عندك زي ما هو:

```
https://vimeo.com/123456789
https://vimeo.com/123456789/abc123def        ← فيديو Unlisted
https://player.vimeo.com/video/123456789
123456789
```

> ### ⚠️ لو الفيديو Unlisted
> Vimeo بيدّيك رابط فيه جزئين: الرقم **و** كود بعده (زي `/abc123def`).
> **لازم تنسخ الرابط كامل بالكود.** لو نسخت الرقم بس، الفيديو مش هيشتغل.

**لو مفيش `vimeo` خالص؟** المستوى هيشتغل عادي ويعرض المحتوى المكتوب، ومكان الفيديو
هيبان فيه رسالة "الفيديو لسه مترفعش". ده الوضع الطبيعي دلوقتي لكل المستويات.

## تضيف كورس جديد إزاي

**١.** اعمل مجلد جديد جوه `content/courses/` باسم الكورس بالإنجليزي وبالشرطات:

```
content/courses/my-new-course/
```

**٢.** اعمل جواه ملف اسمه `course.json` وحطّ فيه:

```json
{
  "title": "My New Course",
  "titleAr": "اسم الكورس بالعربي",
  "subtitle": "سطر وصف قصير",
  "description": "فقرة بتشرح الكورس بيعلّم إيه.",
  "order": 2,
  "plannedLevels": 10
}
```

**٣.** اعمل جواه مجلد اسمه `levels` وابدأ تحطّ ملفات المستويات.

> `plannedLevels` = عدد المستويات اللي الكورس هيبقى فيها لما يخلص.
> الموقع بيستخدمها عشان يقول "٤ من ١٤ متاحين دلوقتي" — يعني بيقول الحقيقة
> للزائر من غير ما تكتبها إنت في كل مكان.

## نصايح كتابة المحتوى

المحتوى بيتكتب بصيغة **Markdown**. الحاجات المهمة:

| عايز تعمل | اكتب |
|-----------|------|
| عنوان قسم | `## ١. عنوان القسم` |
| كلام غامق | `**الكلام**` |
| قايمة | `- عنصر` في كل سطر |
| لينك | `[اسم اللينك](https://example.com)` |
| بلوك كود | تحطّه بين ثلاث علامات ` ``` ` فوق وتحت |

### الليبلات الملوّنة

الموقع بيلوّن الفقرات اللي بتبدأ بليبل غامق وبعده نقطتين، كل واحد بلون مختلف
عشان الصفحة ما تبقاش حيطة كلام:

```
**مثال عملي:** ...        ← بلون البراند
**مصادر:** ...            ← رمادي
**أسئلة تقييم:** ...      ← أزرق
**تمرين:** ...            ← أخضر
**تحذير:** ...            ← أصفر
**قاعدة عملية:** ...      ← بلون البراند
```

أي ليبل تاني هيظهر فقرة عادية — يعني مفيش حاجة هتتكسر لو كتبت ليبل جديد.
