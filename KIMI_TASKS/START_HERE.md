# 👉 كيمي — ابدأ من هنا

## ⚠️ الخطة اتغيرت

المشروع اتحوّل. منصة أتمتة الواتساب بتتلغي بالكامل. بصمة هتبقى:

1. **أكاديمية** — كورس *BASMA AI Automation Engineer Roadmap*، 14 مستوى بالعربي
2. **خدمات** — صفحات خدمات الوكالة

**مفيش داتابيز. مفيش تسجيل دخول. مفيش API routes.** المحتوى هيبقى ملفات في الريبو.

> الملفات `PHASE-0` لحد `PHASE-6` اتنقلت لـ `_archive/` وبقت **ملغية**.
> متشتغلش منها خالص — دي بتوصف منتج مابقاش موجود.

---

## الأمر اللي المفروض تنفذه دلوقتي

```
اقرأ KIMI_TASKS/README.md، وبعدها نفّذ KIMI_TASKS/phases/PHASE-A.md
```

**PHASE-A مرحلة حذف بس.** مش هتبني أي حاجة، مش هتغير التصميم، مش هتعدل النصوص.
الموقع لازم يفضل شكله **مطابق تمامًا** لشكله دلوقتي — بس من غير أي حاجة وراه.

---

## القواعد الخمسة

1. **مرحلة واحدة بس.** خلّص PHASE-A وقف.
2. **متزوّدش من عندك.** الحذف يعني حذف — مش إعادة هيكلة ولا تحسين.
3. **الجيتات لازم تعدي:**
   ```bash
   pnpm lint && pnpm typecheck && pnpm test && pnpm build
   ```
   لو واحدة فشلت ومش قادر تصلّحها — **قف واكتبها في التقرير**.
   متقفلش أي gate، متحطش `eslint-disable`، متعملش `ignoreBuildErrors: true`.
4. **متعملش commit ولا push.** سيب التعديلات في المجلد.
5. **اكتب التقرير** في `KIMI_TASKS/reports/PHASE-A-REPORT.md` (القالب في README)،
   **ومعاه سكرين شوت للصفحة الرئيسية قبل وبعد.**

## قبل ما تحذف أي ملف

اعمل grep الأول. الحذف الجماعي من غير فحص هيكسر البناء بطريقة صعب تتبعها:

```bash
grep -rn "from \"@/lib/<الملف>\"" app components lib hooks config
```

## أداة التصميم (من Phase B وطالع)

اتركّبت **Impeccable** — نظام إرشاد تصميم فيه 59 قاعدة فحص آلية.

**مهم:** كيمي كود **مش** من الـ harnesses المدعومة، يعني أمر `/impeccable` **مش
هيشتغل معاك**. متجربوش. بدالها:

```bash
npx impeccable detect .
```

ده بيشتغل من غير أي harness وبيديك مخالفات محددة بالملف والسطر. وكمان تقدر تقرا
ملفات الإرشاد كماركداون عادي من `.github/skills/impeccable/reference/`.

التفاصيل كلها في `IMPECCABLE.md`.

**ألوان البراند** (مستخرجة من اللوجو): أخضر `#ABE707` + أسود `#000000` + أبيض
`#FFFFFF`. الأخضر **accent بس** — تباينه ممتاز على الأسود وبيفشل WCAG على الأبيض.
